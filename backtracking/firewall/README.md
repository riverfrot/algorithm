# 문제 풀이
링크
코드트리 방화벽 설치하기 (유사문제 - 백준 14502번 연구소 : https://www.acmicpc.net/problem/14502)

## 제한조건
시간제한 2초
메모리제한 512MB
격자 크기: N, M (3 ≤ N, M ≤ 8)

## 시간 복잡도 분석 및 전략
1. 조합 사용 시: 빈칸 중 3개의 벽을 고르는 경우의 수 최악 64C3 = 41,664번 연산.
2. BFS 사용 시: 벽이 세워질 때마다 불을 퍼뜨리는 연산 격자 크기만큼 $O(N*M) = 64번 연산.
   최대 41,664 × 64 ≈ 266만 번의 연산으로 2초(약 2억 번 연산 가능) 내에 해결 가능.

### 해결방안
시간 복잡도 전략: 백트래킹을 통해 3개의 벽을 고르는 모든 경우의 수를 가상 세팅하고, 해당 맵을 카피하여 BFS로 불을 퍼뜨려 안전 영역의 최댓값이 나오게 연산.

### 예외케이스
백트래킹 및 원본 데이터 유지 필요

### 고민했던 흔적들
어떤 경우의수에서 가장 최선일지 모르니 가능한 모든 경우의수에서 데이터 셋팅 및 dfs로 탐색 가능한지를 확인 하여 풀이 진행
