### 고민했던 흔적들
버블소트의 swap 횟수 = 배열의 Inversion Count 
1. 버블소트에서 한 번의 swap은 인접한 두 원소의 역전(i < j인데 A[i] > A[j])을 하나 해소
2. 따라서 총 swap 횟수 = 전체 역전 쌍의 수

펜윅 트리
1.값이 큰 원소부터 처리하면서 "이미 트리에 삽입된 원소 중 내 원래 인덱스보다 앞에 있는 것의 수"를 카운팅
2.같은 값일 때 인덱스도 내림차순 정렬해야 동일 값 쌍이 역전으로 잘못 집계되지 않음
3.query(originIdx - 1)로 자신보다 앞에 이미 삽입된(= 값이 더 큰) 원소 수를 누적

병합 정렬 (Merge Sort)
1.merge 과정에서 오른쪽 배열의 원소가 먼저 들어가는 순간, 왼쪽에 남은 원소 수만큼이 역전 쌍
2.`swapCount += (mid - i + 1)` 한 줄로 자연스럽게 카운팅
3.정답이 int 범위를 초과할 수 있어 long 사용 필요 (N=500,000일 때 최대 약 1.25 × 10^11)
